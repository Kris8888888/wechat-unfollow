# 公众号批量取关（Mac 微信 4.x）

在 Mac 版微信的「关注」窗口里，把关注的公众号全部列出来，按条件筛选、勾选，然后自动一个个取关。跑完会重新扫一遍列表核对，没取关掉的再补一轮。

## 用法

1. 下载 Release 里的 `wechat-unfollow-mac.zip`，解压。
2. 在微信里打开「关注」窗口（能看到「最近更新 / 最近关注」那一页），别最小化。
3. 双击「打开取关工具.command」，浏览器会打开操作界面。终端窗口别关。
4. 第一次点「采集名单」，大约 5 分钟。
5. 用搜索和筛选（最近更新时间、暂不可用、最早关注的 N 个、星标）勾选要取关的号，在右侧清单核对后点「开始取关」。
6. 运行中动一下鼠标或按住 Esc 就会暂停，回来点「继续」。

第一次运行需要在「系统设置 → 隐私与安全性」里给「终端」打开「辅助功能」和「录屏与系统录音」，打开后重启终端。

## 说明

- 工具靠截图识字（macOS 自带的 Vision）和模拟鼠标操作，不读微信数据，也不联网。
- 名单、截图、取关记录都只存在本地 `data/` 文件夹。
- 每个号 3 到 5 秒，太快可能触发微信风控。
- 实测取关率约 95%。没成功的号会在结果里列出原因和截图。

## 从源码编译

需要 Xcode 命令行工具：
